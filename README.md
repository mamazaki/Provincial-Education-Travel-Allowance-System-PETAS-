# Provincial-Education-Travel-Allowance-System-PETAS-
ระบบคำนวณเบี้ยเลี้ยงเดินทางไปราชการ สำนักงานศึกษาธิการจังหวัด
## เทคโนโลยีที่ใช้ (Tech Stack)
- Frontend: HTML5, CSS3, Bootstrap 5
- Libraries: - html2pdf.js สำหรับการส่งออกไฟล์ PDF
- html2canvas สำหรับการบันทึกภาพหน้าจอ
## เครดิตและผู้พัฒนา (Credits)
ออกแบบ และพัฒนาโดย นายสุทธิชัย ชมชื่น
นักวิชาการคอมพิวเตอร์ชำนาญการ กลุ่มนโยบายและแผน
สำนักงานศึกษาธิการจังหวัดอุดรธานี
